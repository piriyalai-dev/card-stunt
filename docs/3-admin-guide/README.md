# คู่มือแอดมิน — ตั้งงานและเผยแพร่

> สิทธิ์ `admin` ครอบทุกอย่าง · `designer` ดูแลชุดสี/ฉาก · `staff` ดูภาพรวม + คุมคิว + export

## 1. สร้างงาน

1. `/admin/home` → **สร้างงาน** ตั้งชื่อ + slug (เช่น `sport69`) + วันที่
2. เข้า event → แท็บ **ภาพรวม**

## 2. ตั้งค่าแสตน (`MANAGE_STANDS`)

- ระบุ ชื่อ, จำนวนแถว × ที่นั่ง, ช่องย่อยต่อคน (default 5×5)
- ตั้งทิศทางแถว/ที่นั่ง (`bottom_to_top`, `left_to_right`) ให้ตรงกับที่เด็กนั่งจริง
  — ถ้ากลับด้าน ภาพผู้ชมจะกลับทั้งผัง
- ระบุ **ช่องปิด/ทางเดิน** บนผัง
- ป้ายแถว/ที่นั่ง: ตัวอักษรหรือตัวเลข + prefix ได้

> ⚠️ เปลี่ยนขนาดแสตนหลังวาดภาพแล้ว = ภาพถูก crop/pad — ระบบจะเตือนก่อนบันทึก

## 3. ชุดสี (`MANAGE_PALETTES`)

- สร้างชุดสี + สี (รหัส / ชื่อไทย / hex / สีตัวอักษร)
- มี preset 12 สี, import/export JSON, auto-contrast
- ลบสีที่ถูกใช้อยู่ ⇒ ต้องเลือกสีทดแทน

## 4. ฉาก (`MANAGE_STUNTS`)

- สร้างฉาก: รหัส, ชื่อ, หมวด, หมายเหตุ, ชุดสี A/B
- **แปลงรูปเป็นพิกเซล** (`/admin/stunts/:id/convert`) — ครอป · ปรับภาพ · CIELAB ΔE2000 · dither
- **Pixel Studio** (`/admin/stunts/:id/studio`) — วาด/แก้, undo 60 ขั้น, ด้าน A/B, draft autosave, revisions
- เรียงลำดับฉากด้วย drag หรือปุ่ม
- เผยแพร่ทั้งงาน: หน้า **ภาพรวม** → **เผยแพร่** (ทุกฉากต้อง `published`)

## 5. ตั้งค่าสำหรับผู้ชม (หน้า ภาพรวม)

| ตัวเลือก | ผล |
|---|---|
| `public_access_enabled` | เปิด/ปิดลิงก์ผู้ชม |
| `roster_lookup_enabled` | ให้ค้นหาที่นั่งด้วยเลขประจำตัว และแสดงชื่อเจ้าของที่นั่ง |
| **เผยแพร่** | bump `published_version` → cache/ETag invalidated, ผู้ชมเห็นข้อมูลใหม่ |

หลังเผยแพร่: ปุ่ม **เปิดหน้าผู้ชม** จะพาไป `/e/<slug>` — ใช้ทดสอบบนมือถือก่อนแจก QR

## 6. Export & คิวสด

- แท็บ **รายชื่อ & Export** (`EXPORT`) — import รายชื่อ + สร้าง PDF/CSV/ZIP
- แท็บ **คิวสด** (`CONTROL_LIVE`) — เลื่อนฉากให้ผู้ชมตาม
- ดูรายละเอียดที่ [`docs/2-staff-operations`](../2-staff-operations/README.md)

## 7. ผู้ใช้และสิทธิ์ (`MANAGE_USERS`)

- 3 บทบาท: `admin` / `designer` / `staff`
- สร้างบัญชีแล้วผู้ใช้ต้องเปลี่ยนรหัสผ่านครั้งแรก
- permission มาจาก `backend/config/roles.json` — แหล่งความจริงเดียว

## 8. เช็กลิสต์ก่อนวันงาน

- [ ] slug สั้น จำง่าย และไม่ซ้ำ
- [ ] แสตนตรงกับผังจริง (ทดสอบด้วยตัวเอง 1 ที่นั่ง)
- [ ] ชุดสีครบ + ชื่อสีภาษาไทยถูกต้อง
- [ ] ฉากทุกฉาก published + เรียงลำดับถูก
- [ ] เปิด `roster_lookup_enabled` ตามนโยบาย
- [ ] เผยแพร่แล้ว และเปิด `/e/<slug>` บนมือถือจริง 1 เครื่อง
- [ ] QR ชี้ `/e/<slug>` — พิมพ์แจก/ขึ้นจอ
