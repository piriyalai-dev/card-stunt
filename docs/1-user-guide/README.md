# คู่มือผู้ใช้ — โหมดนักเรียน (Student Viewer)

> สำหรับนักเรียน/ผู้ชมที่ได้ลิงก์หรือ QR ของงานจากผู้ดูแล · ไม่ต้องสมัคร/ไม่ต้องล็อกอิน

## 1. เปิดโพยของฉัน

1. สแกน QR หรือเปิดลิงก์ `https://<โดเมน>/e/<รหัสงาน>` (เช่น `/e/sport69`)
2. เลือกที่นั่งได้ 2 ทาง
   - **แตะผังแสตน** — เลือกแถว/ที่นั่งจากช่องสี (ช่องเทาคือช่องปิด/ทางเดิน)
   - **ค้นหาเลขประจำตัว** — ใช้ได้เฉพาะงานที่ผู้ดูแลเปิด `roster_lookup_enabled`
3. กด **“เข้าดูโพย”**

ระบบจะจำที่นั่งไว้ในเครื่อง ⇒ เปิดครั้งถัดไปข้ามไปหน้าโพยทันที (ปุ่ม **“เปลี่ยนที่นั่ง”** อยู่มุมขวาบน)

## 2. อ่านโพย (My Cue List)

- แสดงทุกฉากตามลำดับ: เลขลำดับ · รหัสฉาก · ชื่อฉาก · เพลท 5×5 ของที่นั่งคุณ
- แต่ละช่องในเพลทเป็น **รหัสสี** (เช่น 01) แตะ/ชี้ค้างเพื่อดูชื่อสี
- ถ้างานมีด้าน B จะมีสวิตช์ **ด้าน A / ด้าน B** ด้านบน
- ป้าย **v.12** = เวอร์ชันที่เผยแพร่ล่าสุด

## 3. โหมดโฟกัส (ถือใช้งานกลางแสตน)

กด **“เปิดโหมดโฟกัส”** หรือแตะฉากใดก็ได้

| สิ่งที่เห็น | ความหมาย |
|---|---|
| เพลทขนาดใหญ่ | ช่องย่อยทุกช่องของที่นั่งคุณ |
| **รหัสยักษ์ + ชื่อสี** | สีที่ต้องเปิดในฉากนี้ (สีที่ใช้มากที่สุด) |
| “โค้ดถัดไปเตรียมเปิด” | ฉากถัดไปเพื่อเตรียมพลิกป้ายล่วงหน้า |
| ปุ่ม ◀ / ▶ หรือปัดซ้าย-ขวา | เปลี่ยนฉาก |
| dropdown ตรงกลาง | กระโดดไปฉากที่ต้องการ |
| **จอติด** | Screen Wake Lock — กันจอดับ (iOS รุ่นเก่าอาจไม่รองรับ) |

**คิวสด:** ถ้าผู้ดูแลกำลังคุมคิว ป้าย “คิวสด” จะสว่างและโหมดโฟกัสจะเลื่อนตามผู้ดูแลเอง
ถ้าคุณเลื่อนเอง ระบบจะหยุดตามคิวสดให้ (กดป้ายเพื่อกลับมาตามคิวสดได้)

## 4. ใช้ออฟไลน์กลางสนาม

1. เปิดงานขณะมีเน็ต **อย่างน้อยหนึ่งครั้ง** (ระบบจะบันทึกข้อมูลลงเครื่อง)
2. ครั้งต่อไปเปิดได้แม้ไม่มีสัญญาณ — จะเห็นแบนเนอร์ **“กำลังใช้ข้อมูลออฟไลน์”**
3. เมื่อกลับมามีเน็ต ระบบจะอัปเดตข้อมูลให้เอง

> ⚠️ การค้นหาด้วยเลขประจำตัวต้องมีเน็ตครั้งแรก · ที่นั่งที่เคยเปิดแล้วจะใช้ได้ออฟไลน์

## 5. ติดตั้งเป็นแอพ (ไม่บังคับ)

- **Android (Chrome):** เมนู ⋮ → “ติดตั้งแอป” (หรือระบบจะชวนเองเมื่อแตะครั้งแรก)
- **iPhone/iPad (Safari):** ปุ่มแชร์ → “เพิ่มไปที่หน้าจอ”
- เปิดจากไอคอนแล้วระบบจะพากลับไปงานล่าสุดที่เปิด

## 6. ปัญหาที่พบบ่อย

| อาการ | ทางแก้ |
|---|---|
| “เปิดงานไม่ได้” | ตรวจลิงก์/QR ว่ามีรหัสงานถูกต้อง · งานอาจยังไม่ถูกเผยแพร่ |
| ไม่เห็นช่องค้นหาเลขประจำตัว | ผู้ดูแลปิดการค้นหาให้เลือกจากผังแสตนเท่านั้น |
| จอโฟกัสไม่เลื่อนตาม | เน็ตหลุด หรือคุณเลื่อนเองอยู่ — กดป้าย “คิวสด” เพื่อกลับมา |
| จอดับเร็ว | กดปุ่ม “จอติด” (ถ้าเบราว์เซอร์ไม่รองรับจะไม่เห็นปุ่ม) |
| ข้อมูลเก่า | ปิดแท็บแล้วเปิดใหม่ หรือรอการอัปเดตอัตโนมัติ (ตรวจทุก 60 วิ) |
