# คู่มือสตาฟ — วันแข่ง (Live + รายชื่อ + Export)

> ใช้กับแท็บ **“คิวสด”** และ **“รายชื่อ & Export”** ในหน้า event · สิทธิ์ `staff` มี `CONTROL_LIVE`, `MANAGE_ROSTERS`, `EXPORT`

## 1. เตรียมรายชื่อก่อนวันงาน

1. เปิด event → แท็บ **รายชื่อ & Export**
2. เลือก **แสตน** → อัปโหลดไฟล์ **CSV/XLSX**
3. คอลัมน์ที่ต้องมี
   ```
   row,col,student_code,student_name
   1,1,10001,นาย ก
   1,2,10002,นางสาว ข
   ```
   - `row`/`col` เป็นเลข **1-based ตามป้ายบนแสตน** (แถว A = 1, ที่นั่ง 1 = 1)
   - ถ้าใช้คอลัมน์ `row_index`/`col_index` ระบบจะถือว่าเป็น **0-based**
   - `student_name` ห้ามว่าง · ช่องซ้ำ/ช่องปิดจะถูกรายงานในผล import
4. ตรวจผล: “นำเข้า X/Y แถว” + รายการ error (ถ้ามี)
5. ตรวจในตารางด้านล่างด้วยช่องค้นหา (ชื่อ / เลข / ที่นั่ง)

> 💡 ถ้าต้องการให้เด็กค้นหาด้วยเลขประจำตัวได้ ให้แอดมินเปิด **“ค้นหาด้วยเลขประจำตัว”** ในหน้าภาพรวมงาน

## 2. สร้างไฟล์ส่งออก (Export)

| รูปแบบ | ได้อะไร | ใช้เมื่อ |
|---|---|---|
| **PDF** | การ์ดโพยรายที่นั่ง 4 ใบ/หน้า A4 — ที่นั่ง, ชื่อ, ทุกฉาก + เพลทสี | พิมพ์แจกเด็ก / ติดโต๊ะ |
| **CSV** | ตารางทุกที่นั่ง × ฉาก (ด้าน A/B, รหัสสีทุกช่อง) | ตรวจสอบ/ทำ pivot ใน Excel |
| **ZIP** | ภาพกริดเต็มทุกฉาก (PNG) + `seats.csv` + `manifest.json` | เก็บเป็นหลักฐาน/ส่งต่อ designers |

ขั้นตอน
1. เลือก **ขอบเขต** = ทั้งงาน หรือเฉพาะแสตน
2. กดปุ่มรูปแบบที่ต้องการ → งานจะเข้าคิว (สถานะ **รอคิว** → **กำลังสร้าง** → **เสร็จ**)
3. เมื่อ **เสร็จ** กด **ดาวน์โหลด** · ถ้า **ล้มเหลว** กด **ลองใหม่**
4. ไฟล์ถูกเก็บใน volume `pixelstand_export_data` (retention ตาม `EXPORT_MAX_AGE_DAYS`)

> ⚠️ PDF จำกัดจำนวนที่นั่ง (`EXPORT_MAX_SEATS_PDF`, default 5,000) — งานใหญ่ให้ export แยกแสตน

## 3. คุมคิวสดวันแข่ง

1. เปิด event → แท็บ **คิวสด**
2. เลือกฉากจาก dropdown หรือกดรายการด้านล่าง → **“ไปฉากนี้”**
3. ใช้ปุ่ม ◀ / ▶ เพื่อเลื่อนคิว
4. ผู้ชมที่เปิดหน้าโฟกัสจะเลื่อนตามภายในไม่กี่วินาที (SSE)
   - ถ้าผู้ชมปิด “ตามคิวสด” เขาจะยังเลื่อนเองได้ — ไม่ block การใช้งาน

**ข้อควรระวัง**
- คิวสดใช้เฉพาะฉากที่ **published** เท่านั้น — ถ้ารายการว่าง ให้ publish งานก่อน
- ผู้ชมที่หลุดเน็ตจะไม่เลื่อนตาม แต่ยังเปิดโพยของตัวเองได้ (ข้อมูลออฟไลน์)

## 4. เช็กลิสต์ก่อนเปิดสนาม

- [ ] รายชื่อ import ครบทุกแสตน ไม่มี error
- [ ] เปิด “ค้นหาด้วยเลขประจำตัว” ตามนโยบายโรงเรียน
- [ ] เผยแพร่งาน (publish) และเปิดหน้าผู้ชมทดสอบ 1 เครื่อง
- [ ] PDF/CSV สำรองพิมพ์ไว้ 1 ชุด
- [ ] ตั้งคิวสดที่ฉากแรกแล้ว
- [ ] มีคนถือ iPad/โน้ตบุ๊กคุมคิวสดตลอดงาน
